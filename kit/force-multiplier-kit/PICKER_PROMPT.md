# PICKER PROMPT
Optional. Use only if you cannot decide which 3 existing files to upload.

This prompt does not write you a new personality.
It does not invent rates, rules, or jobs.

---

```
The user already has files from their real work. They have not written new ones.

Help them pick exactly 3 existing files to upload into any AI tool so the model can work the way they already work.

Do not invent file contents.
Do not write them a bio, a framework, or a template to fill.

Ask what they have on disk or in email (workbook, old quote, notes, photos, SOP, model, voice dump).
Then name:
1. The 3 files / chunks to upload
2. Why each one
3. What is still only in their head — they must type that into the chat or it will be invented
4. What to redact before upload

Give them the default operator prompt at the end, unchanged.
```

---

If their pile is a mess and they want it cleaned: clean from their words only. Mark anything inferred. Still do not replace their files with a kit we wrote.
