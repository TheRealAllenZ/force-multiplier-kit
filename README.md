## How to use the kit
1. Read `WHAT_TO_UPLOAD.md` and pick the three files you already use for the job.
2. Open any AI chat (ChatGPT, Claude, Gemini, Grok…), upload the files.
3. Paste `PROMPT.txt`. Use `PICKER_PROMPT.md` if you're not sure which job to duplicate first.
4. Follow `HOW_TO_RUN.md`; `OPERATOR_PROMPTS.md` has follow-ups.
